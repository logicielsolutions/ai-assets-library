# Handovers

One file per video session: `YYYY-MM-DD_<project-slug>.md`. The newest one wins.

To continue a video, start Claude in the workspace and say:

```
Read projects/handovers/<file>.md and continue. <what you want next>
```

## What a handover holds
- Status: where the video stands, what's pending
- Links: latest MP4, project folder, review pages
- Timing: voiceover lines with start times, music grid
- Scenes: what plays when, which asset, which word it lands on
- Decisions and preferences, so they don't get re-argued
- How to rebuild the audio and the final MP4
- Gotchas hit along the way
